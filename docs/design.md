# SC Telegram App — проектные решения

Telegram Mini App для монтажников (кондиционирование и вентиляция), фирма в Грузии.
Монтажник после работ заполняет отчёт: объект, работы по прайсу, расход материалов, фото.
Бот публикует отчёт в рабочую группу, приложение считает заработок.

Статус на 2026-10-25: каркас готов (монорепо, БД, авторизация, бот, сквозной «Привет, {имя}»). Как запускать — README.md.

## Ключевые решения

- **Бот не может писать от имени пользователя.** Отчёт в группу публикует бот, указывая автора и участников.
- **Сумм в группе нет.** Заработок монтажник видит в профиле по дням.
- **Бригады:** один человек заполняет отчёт и отмечает участников, деньги делятся **поровну**.
  Доля каждого фиксируется при отправке (`report_participants.amount`), копеечный остаток идёт автору.
- **Отчётов может быть несколько в день** (несколько объектов), можно отправить и после окончания работ (дата задним числом).
- **Объект — не справочник.** В отчёте есть поля `address` (с подсказками из прошлых отчётов) и `location` (этаж/квартира, свободный текст).
- **Работы и материалы разделены:** это два справочника и два блока в форме и сообщении. Материалы пока только учитываются по расходу, без склада.
- **Ступенчатые цены** (закладка трасс, гибкие воздуховоды): ступень выбирается по сумме метров этой работы в отчёте.
- **Дневной оклад:** 70 ₾ в будни, 100 ₾ в выходные (по дате работ), ставки меняет админ. Каждому участнику, один раз за день, не делится, без коэффициента за высоту; фиксируется при отправке первого отчёта за день (`daily_wages`).
- **Работы на высоте > 4,5 м:** галочка на весь отчёт, сумма × 1,2.
- **Договорные объекты** (застройщики, ТЦ) через приложение не проходят.
- **Сумму считает бэкенд**, цена фиксируется снапшотом в строке отчёта. Деньги хранятся в целых минимальных единицах (тетри/копейки).
- **Авторизация:** HMAC-проверка `initData` на бэкенде + белый список `users.is_active`. Роли: `installer`, `admin`.

## Стек

| Слой | Выбор |
|---|---|
| Монорепо | pnpm workspaces: `apps/web`, `apps/api`, `packages/shared` |
| Фронт | Vite + React + TS + Redux Toolkit + RTK Query; Telegram API через официальный `telegram-web-app.js` (+ `@types/telegram-web-app`) |
| Валидация | zod (общие схемы в `packages/shared`) |
| Бэкенд | Node 24 (запускает .ts без сборки) + Fastify + grammY, API и бот в одном процессе; initData проверяется `@tma.js/init-data-node` |
| БД | PostgreSQL + Drizzle |
| Фото | сжатие на клиенте (1600 px, JPEG) → диск сервера (`PHOTOS_DIR`, модуль `photos/storage.ts` можно заменить на R2) → альбом в Telegram, храним путь и `file_id` |
| Деплой | DigitalOcean Droplet (FRA1, Ubuntu 24.04) + docker compose: caddy, api, postgres, backup (pg_dump → R2) |
| Dev | туннель `cloudflared tunnel --url localhost:5173` для HTTPS |

## Схема данных

```
users                id, telegram_id, name, role (installer|admin), is_active
price_items          id, category (conditioning|ventilation), name, unit, price, tiers (jsonb, ступени по объёму), is_active
materials            id, category, name, unit, is_active
reports              id, author_id, address, location, work_date, comment, at_height,
                     status (draft|sending|sent), total_amount, tg_message_ids, created_at, sent_at
report_participants  report_id, user_id, amount
report_works         report_id, price_item_id, qty numeric(10,2), unit_price_snapshot, amount
report_materials     report_id, material_id, qty numeric(10,2)
report_photos        report_id (null — ещё не прикреплено), uploader_id, storage_key, tg_file_id, sort_order, created_at
```

## Формат сообщения в группу

```
📍 Багратиони 196И · 10 этаж
📅 24.10.2026 · 👷 Иван Петров, Сергей Ким

🔧 Работы
❄️ Кондиционирование
• Монтаж блоков — 2 шт
🌀 Вентиляция
• Отверстие под приточку ⌀100 — 2 шт

📦 Материалы
• Дренаж — 2 м
• Труба ⌀110 — 0,3 м

💬 Приточка без монтажа
```

Фото уходят альбомом. Если текст длиннее 1024 символов (лимит подписи), он отправляется отдельным сообщением после альбома.

## Экраны

1. Новый отчёт: адрес/этаж → дата → участники → работы → материалы → фото → комментарий → отправить.
2. Мои отчёты: черновики и отправленные.
3. Профиль: заработок по дням и за месяц.
4. Админ: прайс, материалы, монтажники.

## Подводные камни

- Плохая связь: сжимать фото на клиенте (~1600px), загружать по одному сразу после выбора.
- Mini App может закрыться: черновик хранится на сервере (`status = draft`).
- Идемпотентность: отчёт со статусом `sent` повторно не отправляется.
