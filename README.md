# SC Telegram App

Telegram Mini App для отчётов монтажников. Проектные решения — в [docs/design.md](docs/design.md).

```
apps/api         Fastify + grammY + Drizzle (Node 24 запускает .ts напрямую, без сборки)
apps/web         Vite + React + Redux Toolkit / RTK Query
packages/shared  zod-схемы, типы DTO, расчёт денег — общие для фронта и бэка
```

## Первый запуск

```bash
nvm use                       # Node 24
cp .env.example .env          # заполнить BOT_TOKEN, ADMIN_TELEGRAM_IDS, DEV_TELEGRAM_ID
pnpm install
pnpm db:up                    # Postgres в Docker
pnpm db:migrate
pnpm db:seed                  # админы + справочники из apps/api/seed/*.csv
pnpm dev                      # API на :3000, фронт на :5173
```

Свой Telegram ID можно узнать, написав боту `/start`.

## Разработка фронта

- **В обычном браузере** (`http://localhost:5173`): запросы идут без initData, и API в dev-режиме
  выполняет их от имени `DEV_TELEGRAM_ID`.
- **Внутри Telegram**: нужен HTTPS.
  1. `cloudflared tunnel --url http://localhost:5173` — выдаст адрес `https://….trycloudflare.com`.
  2. Записать его в `WEBAPP_URL` в `.env` и перезапустить `pnpm dev`. Бот сам выставит кнопку меню «Отчёт».

Адрес туннеля меняется при каждом запуске; постоянный можно получить именованным туннелем Cloudflare.

## Авторизация

Фронт отправляет `Authorization: tma <initData>`, бэкенд проверяет подпись токеном бота
(`apps/api/src/auth.ts`) и пускает только активных пользователей из таблицы `users`.

## API

Все запросы — с заголовком `Authorization: tma <initData>`. Типы ответов — в `packages/shared/src/schemas.ts`.
Деньги — целые тетри (1 ₾ = 100), количество — число с двумя знаками после запятой.

| Метод | Путь | Что делает |
|---|---|---|
| GET | `/api/me` | Текущий пользователь (`MeDto`) |
| GET | `/api/me/earnings?from=YYYY-MM-DD&to=YYYY-MM-DD` | Заработок по дням: доли по отправленным отчётам + дневной оклад (`EarningsDto`) |
| GET | `/api/catalog` | Активные работы с ценами, материалы и ставки оклада (`CatalogDto`) |
| GET | `/api/users` | Активные пользователи для выбора участников бригады |
| GET | `/api/reports` | Отчёты, где я автор или участник (`ReportListItemDto[]`) |
| POST | `/api/reports` | Создать черновик (`ReportDraftInput`) → `ReportDto` |
| GET | `/api/reports/:id` | Отчёт целиком (`ReportDto`) |
| PUT | `/api/reports/:id` | Перезаписать черновик целиком (только автор) |
| DELETE | `/api/reports/:id` | Удалить черновик (только автор) |
| POST | `/api/reports/:id/send` | Зафиксировать цены и доли, опубликовать в группу |
| POST | `/api/photos` | Загрузить фото (multipart, поле `file`, только JPEG до 10 МБ) → `{ id }` |
| GET | `/api/photos/:id` | Фото (видят загрузивший и участники отчёта) |
| DELETE | `/api/photos/:id` | Удалить своё фото, если отчёт ещё не отправлен |
| GET | `/api/payroll` | Мои недельные отчёты на выплату (последние 10) |
| POST | `/api/payroll` | Отправить неделю на выплату `{ weekStart }` (понедельник); бот пишет активным админам |

Админка (только роль `admin`, иначе `403`):

| Метод | Путь | Что делает |
|---|---|---|
| GET / POST | `/api/admin/price-items` | Все работы, включая скрытые / добавить (`PriceItemInput`, цена в тетри) |
| PUT | `/api/admin/price-items/:id` | Изменить работу целиком; `isActive: false` скрывает её из формы |
| GET / POST | `/api/admin/materials` | То же для материалов (`MaterialInput`) |
| PUT | `/api/admin/materials/:id` | |
| GET / POST | `/api/admin/users` | Все пользователи / добавить по Telegram ID (бот напишет человеку) |
| PUT | `/api/admin/users/:id` | Изменить; снять с себя роль admin или отключить себя нельзя |
| GET / PUT | `/api/admin/wage-rates` | Ставки дневного оклада `{ weekday, weekend }` в тетри |
| GET | `/api/admin/payroll` | Люди и их последний недельный отчёт на выплату |
| GET | `/api/admin/payroll/:userId?limit=5` | Последние N недельных отчётов человека (1–52) |

| DELETE | `/api/admin/price-items/:id`, `/api/admin/materials/:id` | Удалить позицию, которой нет ни в одном отчёте; иначе `409` — её можно только скрыть |

Людей не удаляют, а отключают: на них ссылаются отчёты.

Как устроены отчёты:
- Ступенчатая цена (`tiers`): цена за единицу выбирается по количеству этой работы в отчёте; `upTo` — граница включительно, у последней ступени `null`.
- Дневной оклад (по умолчанию 70 ₾ в будни, 100 ₾ в сб и вс по дате работ) начисляется каждому участнику
  один раз за день — при отправке первого отчёта за эту дату; ставка фиксируется в `daily_wages`.
  Коэффициент за высоту на оклад не влияет.
- `atHeight: true` — работы на высоте выше 4,5 м: вся сумма отчёта × 1,2, в группе появляется пометка.
- Фото: сначала `POST /api/photos`, затем их `id` в `photoIds` черновика (до 10, в порядке показа).
  При отправке — альбом с текстом отчёта в подписи; если текст длиннее 1024 символов, он уходит отдельным сообщением.
  Фото без отчёта старше двух суток сервер удаляет сам.
- Автор автоматически становится участником; в `participantIds` передаются только остальные члены бригады.
- Сумма пересчитывается при каждом сохранении черновика (предварительная) и окончательно — при отправке по текущему прайсу. После отправки отчёт не меняется.
- Повторная отправка уже отправленного отчёта возвращает его без повторной публикации; параллельная — `409`.
- Если Telegram не принял сообщение — `502`, отчёт остаётся черновиком.
- Ошибки: `400` (валидация, текст в `message`), `403` (не автор), `404`, `409` (отчёт уже отправлен).

## База данных

- Схема: `apps/api/src/db/schema.ts`. После изменения: `pnpm db:generate` → `pnpm db:migrate`.
- Просмотр данных: `pnpm db:studio`.
- Справочники: скопировать `apps/api/seed/*.example.csv` в `price_items.csv` / `materials.csv`,
  заполнить (можно в Excel, сохранить как CSV) и выполнить `pnpm db:seed` — повторный запуск обновляет записи.
  Ступени цены — необязательная колонка `tiers`: `6:8|10:7|*:6` (до 6 — 8 ₾, до 10 — 7 ₾, больше — 6 ₾).
  Настоящие CSV в git не попадают (см. `.gitignore`): репозиторий публичный.
  Seed нужен для первичной загрузки: он ищет позиции по названию. После правок в админке не запускайте его
  на той же базе со старым CSV — переименованная позиция появится заново, а изменённые цены откатятся.
